Sultan’s Game

A browser remake of the SDDYX game.

Open Project Source repository

Getting started

Start a new game or continue from a browser save. Progress through the opening story and use the card-based interface to make decisions. The first visit downloads a substantial set of game resources. Continue becomes available when the first round begins; the opening introduction alone does not enable it.

Before you start

Projects open in their own pages. Where a project stores progress in your browser, export a save before clearing site data or changing devices.
