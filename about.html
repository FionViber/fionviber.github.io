About this collection

FionViber is a personal collection of browser tools, experiments and games. This website brings their launch links and project notes together in one place.

Getting started

Choose Tools or Games to browse, or search by project name. Open a project guide for practical notes before launching. Some projects use a password supplied separately.

Source repository

The collection includes browser adaptations and mirrors as well as standalone tools. Source repositories provide the context for each project.
